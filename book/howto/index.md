# How-to guides

Use these guides after the Quickstart when you want to shape a worker for a real role, wire approvals, or diagnose an existing run.

## Build and operate

- [Build a vertical](./build-vertical.md) turns a plain-English role idea into a checked vertical on disk.
- [Pick a vertical](./pick-a-vertical.md) helps you choose an existing template before creating a new one.
- [Set up approval channels](./approvals.md) connects the worker to the human who approves risky work.
- [Troubleshoot a stuck worker](./troubleshoot.md) walks the fastest checks when work stops moving.
