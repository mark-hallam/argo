# Skill: Post Inline-Skate Listing

Use this checklist when drafting or posting an inline-skate listing.

1. Confirm facts from `inventory.json`: model, size, condition, inclusions, and
   known issues.
2. Ask for photos in this order: hero side profile, cuff/liner size label,
   soulplate and frame wear, wheels/bearings close-up, included extras.
3. Price in AUD and mention Bulleen / Melbourne pickup only when the operator
   has approved the location wording.
4. Keep the listing body short: model, fit notes, condition, inclusions, pickup
   or shipping terms, and one clear call to action.
5. Public posting and buyer messaging always require approval.
