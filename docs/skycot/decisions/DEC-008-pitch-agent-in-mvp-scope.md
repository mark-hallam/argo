# DEC-008 — Pitch Agent is IN v1.0 MVP scope

- **Date**: 2026-05-24
- **Decided by**: Mark Hallam (operator)
- **Status**: active
- **Supersedes**: original PRODUCT_ROADMAP framing where Pitch was a
  post-MVP / beyond-v1.0 headline feature

## Decision
The Pitch Agent (Track P) is part of the v1.0 MVP, not a post-v1.0 feature.
The v1.0 ship gate expands to require the Track P brief tree shipped before
the demo MP4 records. The Pitch Agent is the v1.0 demo headline.

## Rationale
Operator strategic call: the Pitch Agent proves all 6 mission claims
recursively (an agent pitches Skycot) and is the most compelling demo
moment. Worth folding into MVP scope despite the timeline cost.

## Timeline impact (the misalignment this register fixes)
This expanded MVP scope beyond the original v1.0 definition. The phase docs
(BUILD_PLAN_V11, PRODUCT_ROADMAP) were not updated at decision-time, so the
"v1.0" we ship is materially larger than originally planned. See
DEC-010 (Genesis) + DEC-009 (computer-use) for the other in-scope additions.
As of 2026-05-29 all Track P briefs (P-01..P-05, P-08) are MERGED + the
operator-facing /pitch surface + LLM-fallback path shipped.

## How to apply
Track P work is v1.0-blocking, not deferrable. Treat Pitch surfaces as
demo-critical-path.
