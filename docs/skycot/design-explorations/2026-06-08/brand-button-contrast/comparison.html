My read (first-principles, long-term): the solid #7C3AED (violet-600) is the cleanest fix — it's still unmistakably "your purple," passes AA with margin, and a single token change fixes every solid primary button at once. The gradient is a separate story: white-on-pink is 3.53:1 at the pink end regardless of the purple, so a gradient button only truly passes if either the pink end is darkened to #DB2777 (option 3, keeps the look, both ends pass) or we add a subtle text-shadow (option 4, zero colour change). Gradient CTAs are usually large hero text, so they often qualify as "large text" (3:1) and are defensible as-is — but #DB2777 is the no-asterisk fix. None of this touches the gradient direction or the brand fonts.
