A.I. WORKERS, AUDIT-FIRST

Software that takes orders
instead of orders being given through it

SKYCOT compiles plain-English job descriptions into AI workers that live in Slack, learn from your feedback, and ask for approval like a teammate. Every action is hash-chained, replayable, and auditable by an outsider. Built single-binary in Rust.

$ skycot hire --first read the spec →
$ curl -sS skycot.com/install | sh [copy]
PRIMITIVE 01

Memory that compounds

Each worker keeps a private memory of what you've taught it. Survives model swaps. Owned by you.

~30k facts/worker · sqlite-encrypted at rest
PRIMITIVE 02

Approve where you live

Slack, email, SMS, voice. Workers ask in your existing channel. No new dashboard.

6 channels · <200ms ask latency
PRIMITIVE 03

Audit by default

Hash-chained log per session. Replay any decision. SOC 2 / GDPR as side effect.

SHA-256 chain · <1ms verify/row
