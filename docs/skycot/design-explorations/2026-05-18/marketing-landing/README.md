# Marketing landing — design exploration (2026-05-18)

Five wildly different design directions for the SKYCOT marketing landing page. The optometrist method: each pole is a different design language, and the operator picks which gives the strongest "yes."

## How to use

1. Open all 5 files in tabs (double-click each in Finder, or right-click → Open With → Chrome).
2. Look at each one in turn. Don't analyze — react. Gut reaction in 5 seconds.
3. Tell me which one (or which two) feel right, and what you'd tweak.
4. I'll then produce 2-3 variations IN THAT direction so we can narrow down.

## The 5 options

| File | Design language | Voice | Best for | Trade-off |
|---|---|---|---|---|
| [option-A-editorial.html](./option-A-editorial.html) | Editorial / Magazine cover | Literary, confident, sparse | Category-defining positioning | Slower to read |
| [option-B-industrial.html](./option-B-industrial.html) | Industrial / Dev-tool / Terminal | Technical, honest, no fluff | Technical buyers, dev-tool market | Cold to non-technical buyers |
| [option-C-apple-minimal.html](./option-C-apple-minimal.html) | Apple-minimal / Silent confidence | One huge sentence per scroll | Premium positioning | Demands a polished product |
| [option-D-friendly-illustrated.html](./option-D-friendly-illustrated.html) | Hand-drawn / Friendly / Illustrated | Like a teammate over coffee | SMB / nervous first-time AI buyer | Can feel "small" for enterprise |
| [option-E-brutalist.html](./option-E-brutalist.html) | Brutalist / Statement piece | Loud, asymmetric, confident | Standing out / viral potential | Hostile to risk-averse buyers |

## What's next

After you pick a direction:

1. I'll produce 2-3 variants IN that direction (e.g. if A, try "more white space" vs "more illustrations" vs "denser type")
2. We narrow until you have a winner
3. I author an implementation brief for the swarm to rebuild `marketing/` to match
4. We do the same for the next page (recommend the audit page — it's the showpiece)
