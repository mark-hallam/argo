## Scope

P1. Design partner program for 3 early customers. Each partner gets:
- White-glove onboarding (operator + screen-share).
- Pro tier free for first 3 months.
- Direct line to founder (operator).
- Dedicated `#partner-<name>` channel on Discord.
- Quarterly check-ins for feedback.
- In exchange: case study + testimonial post-90-days.

Deliverable: playbook for operator to execute (not code).

LOC: ~250.
