# mission-default-pack-catalog-bundled-in-binary — embed default pack catalog into binary at build time

**Owner**: claude or codex. **Depends on**: `mission-skill-library-bootstrap-on-fresh-install` — this brief refines the bundled-source mechanic.
**Authored against**: origin/main `289d3077f` on `2026-05-25`.
**Validate before claim**: `bash scripts/check-brief-freshness.sh mission-default-pack-catalog-bundled-in-binary`.

## Why this is P3

Companion to `mission-skill-library-bootstrap-on-fresh-install`. Once bootstrap exists, we need a stable embedded source so the binary is self-contained — no network fetch required, no surprise blank installs even if `packs/` is missing on the build machine.

## Scope

1. Decide the embedding strategy: `include_str!` per pack file (simple, large binary) vs. tarball-then-decompress (smaller binary, more complex), vs. const slice of `(path, bytes)` pairs (compile-time, no runtime overhead).
2. Recommend option (c) — `const PACKS: &[(&str, &[u8])] = &[...]` generated by a `build.rs` script walking the `packs/` repo directory.
3. Implement: add `crates/argo-vertical-packs/build.rs` that emits `pub const BUNDLED_PACKS: &[(&str, &[u8])]` covering every file under `packs/` recursively.
4. Expose `PackLoader::bundled() -> &[(&str, &[u8])]` so the bootstrap can write them to disk on first run.
5. Tests at `crates/argo-vertical-packs/tests/bundled_catalog_test.rs` (~100 LOC): assert ≥5 packs in `BUNDLED_PACKS`; assert each has a `pack.toml`; assert each toml parses.
